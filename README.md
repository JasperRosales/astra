# ✦ Astra — a journal written in stars

**Live:** https://jasperrosales.github.io/astra/

Astra is a private journal where every entry becomes a star in your own night sky. Over time, your memories form constellations you can explore, search and replay.

## Why
Journals are lists, and lists are easy to forget. Astra makes your past *something you want to look at*: the good weeks glow, the hard ones show up as storm-red stars, and the chapters of your life connect into constellations.

## Features
- **Entry → star** — mood sets the color (Joyful, Calm, Loved, Hopeful, Blue, Stormy), importance sets brightness.
- **Constellations** — entries with the same constellation name are linked in chronological order and labeled.
- **Explorable sky** — drag to pan, scroll/pinch to zoom, drag stars to rearrange, parallax starfield, shooting stars.
- **Timeline & replay** — scrub to see your sky on any past day, or press ▶ to watch it form star by star.
- **Search** — matching stars stay lit, the rest dim.
- **Sky report** — totals, best journaling streak, mood spectrum, brightest memories.
- **Browse** — earlier/later navigation, full entry list, "revisit a random memory".
- **Own your data** — stored only in your browser (localStorage); export/import JSON, save the sky as a PNG.
- Responsive (phone bottom-sheet layout), keyboard shortcuts (`N`, `/`, `←` `→`, `Esc`).

## Tech
Plain HTML, CSS and JavaScript with the Canvas 2D API — no frameworks, no build step, no backend. Hosted on GitHub Pages.

## Run locally
Open `index.html` in a browser, or `python3 -m http.server` in this folder.
